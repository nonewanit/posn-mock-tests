\question โปรแกรมที่ใช้ในการหาค่าสัมบูรณ์นี้มีจุดผิดพลาด โปรแกรมนี้ไม่ได้ให้ผลที่ถูกต้องทุกครั้ง ข้อใดมีส่วนที่ไม่ถูกต้อง
\begin{pseudocode}
\begin{enumerate}
    \item รับจำนวนจริง และบันทึกไว้ที่ตัวแปร P 
    \item ถ้า p >= 0
    \begin{enumerate}
        \item พิมพ์ p
    \end{enumerate}
    \item ถ้า p <= 0
    \begin{enumerate}
        \item ให้ p เท่ากับ p คูณ -1
        \item พิมพ์ p
    \end{enumerate}
\end{enumerate}
\end{pseudocode}
\choicesvertical{จำนวนจริงบางจำนวนหาค่าสัมบูรณ์ไม่ได้}{มีบางจำนวนที่โปรแกรมแสดงค่า |p| ซ้ำสองรอบ}{ไม่สามารถคูณบางจำนวนด้วย -1 เพื่อกลับเครื่องหมายได้}{มีบางจำนวนที่จะไม่เข้าทั้งสองเงื่อนไข}
