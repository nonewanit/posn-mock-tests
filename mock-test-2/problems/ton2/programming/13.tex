\question พิจารณาโปรแกรมต่อไปนี้ ตัวแปร m จะมีค่าเท่าใดเมื่อสิ้นสุดการทำงาน
\begin{verbatim}
numbers = [3, 7, -1, -3, 5, -13, 0]
m = 0
n = len(numbers)
i = 0
while i < n:
    if numbers[i] >= 0 and numbers[i] > m:
        m = numbers[i]
    if numbers[i] < 0 and numbers[i] * -1 > m:
        m = numbers[i] * -1
    i = i + 1
print(m)
\end{verbatim}
\choiceshorizontal{0}{7}{-13}{13}
% answer: 4
