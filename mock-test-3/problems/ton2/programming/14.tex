\question พิจารณาโปรแกรมภาษาไพธอนต่อไปนี้ เมื่อโปรแกรมทำงานเสร็จสิ้นจะแสดงผลลัพธ์เป็นเท่าใด
\begin{verbatim}
x = 15
ans = 0
i = 1

while i <= 3:
    j = 3
    while j > 0:
        if (i * j) % 2 == 0:
            x = x - j
            ans = ans + x
        else:
            x = x + i
            ans = ans + (x % 5)
        j = j - 1
    i = i + 1

print(ans)
\end{verbatim}
\choiceshorizontal{52}{57}{59}{61}
% answer: 4
