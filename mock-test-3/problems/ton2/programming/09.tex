\question พิจารณาโปรแกรมภาษาไพธอนต่อไปนี้ เมื่อโปรแกรมทำงานเสร็จสิ้น ค่าของตัวแปร \texttt{count} ที่ถูกแสดงผลคือข้อใด
\begin{verbatim}
n = 18
count = 0

while n > 1:
    if n % 2 == 0:
        n = n // 2
    elif n % 3 == 0:
        n = n + 1
    else:
        n = n - 1
    count = count + 1

print(count)
\end{verbatim}
\choiceshorizontal{4}{5}{6}{7}
% answer: 3
