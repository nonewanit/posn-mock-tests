\question กำหนดเงื่อนไขดังนี้ \newline
ถ้า age < 15 และ gender == "M" \quad ผลลัพธ์ คือ เด็กชาย \newline
ถ้า age < 15 และ gender == "F" \quad ผลลัพธ์ คือ เด็กหญิง \newline
ถ้า age >= 15 และ gender == "M" \quad ผลลัพธ์ คือ นาย \newline
ถ้า age >= 15 และ gender == "F" และ marital == "S" \quad ผลลัพธ์ คือ นางสาว \newline
ถ้า age >= 15 และ gender == "F" และ marital == "M" \quad ผลลัพธ์ คือ นาง \newline
ข้อใดคือผลลัพธ์ ถ้า age = 15, gender = "F" และ marital = "M"
\newline
\choiceshorizontal{เด็กหญิง}{นาย}{นางสาว}{นาง}
% answer: 4
