\question ข้อใดคือรายการข้อมูลของ data หลังโปรแกรมทำงานเสร็จ
\begin{verbatim}
data = [60, 20, 10, 50, 40, 30]
i = 0
n = len(data)
while i < n:
    j = 0
    while j < n - 1:
        if data[j] < data[j+1]:
            temp = data[j]
            data[j] = data[j+1]
            data[j+1] = temp 
        j = j + 1
    i = i + 1
print(data)
\end{verbatim}
\choicesgrid{[10, 20, 30, 40, 50, 60]}{[30, 40, 50, 10, 20, 60]}{[60, 20, 10, 50, 40, 30]}{[60, 50, 40, 30, 20, 10]}
